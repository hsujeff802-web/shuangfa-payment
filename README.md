# 雙發付款管理系統 V8.3 RC Build 0293 正式版候選版

## RC Build 0293 系統設定密碼保護
- 點選首頁「系統設定」前，必須輸入目前登入密碼。
- 密碼沿用登入帳號的雜湊驗證，不保存明碼，也不新增另一組設定密碼。
- 密碼錯誤或取消時留在首頁；每次重新進入系統設定都會再次驗證。

## RC Build 0292 綠色新增付款入口調整
- 加號移到「新增付款」文字最後，顯示為「新增付款＋」，緊貼「款」字。
- 移除綠色卡片左上角獨立加號，避免與標題或主要入口標籤重疊。
- 修正主要入口標籤定位，並調整手機版內距、標題行高與置中方式。

## RC Build 0291 新增收款入口美化
- 首頁「新增付款」綠色大卡改為主要功能入口資訊卡。
- 新增「廠商 → 月份 → 金額 → 簽名」流程提示。
- 顯示多月份及現金／客票／支票等支援項目，手機版仍維持滿版與大按鈕。

## RC Build 0290 登入帳號與密碼修改
- 登入後的「系統設定」新增目前登入帳號、新登入帳號欄位。
- 可只修改登入帳號、只修改密碼，或同時修改兩者。
- 變更前必須輸入目前密碼；新帳號不得與其他帳號重複。
- 修改帳號後會同步更新目前登入狀態，下一次登入使用新帳號即可。
- 保留預設帳號 admin；第一次安裝仍可用 admin／1234 登入後再修改。
- 密碼只保存雜湊值，不會在畫面或備份檔中顯示明碼。

## RC Build 0290 發行前整理
- 本版由 DEV Build 0276 複製整理，作為正式版前最後測試候選版。
- 保留離線使用、手機內部完整備份、照片／簽名保存、月份區間與混合付款功能。
- 登出、閒置登出及清除付款資料前，備份完成並讀回驗證後才會繼續。
- 修改紀錄新增／移除會等待保存完成；保存失敗會回復原紀錄，不會只顯示假成功。
- 移除存檔後重複播放的舊語音輪詢，付款完成語音只保留一次。
- Service Worker 與程式查詢字串已更新為 0290，避免手機沿用舊版快取。
- 正式發布前請先用測試資料完成新增、查詢、修改、銷帳、列印、備份與還原測試。

## Build 0269 儲存與刪除流程檢修
- 登出、閒置登出及清除付款資料時，完整備份獨立保存於手機內部資料庫。
- 刪除單筆付款時同步移除該筆修改紀錄，並恢復關聯支票為未使用。
- 清除付款資料後會重新讀回驗證，失敗時保留原資料。
- IndexedDB 與 localStorage 會依最後保存時間判斷，避免舊資料覆蓋新資料。

## Build 0268 登出自動內部備份
- 登出前由系統直接將完整付款資料、照片與廠商簽名保存到手機 IndexedDB。
- 備份完成後才登出，不會自動開啟 JSON 下載預覽頁。
- 「立即完整備份」仍保留給需要另存 JSON 檔案時使用。

## Build 0267 閒置備份加強
- 閒置自動登出前先將完整資料寫入手機內部資料庫，不需要按任何按鍵。
- 同時嘗試產生下載備份檔；即使瀏覽器阻擋自動下載，內部備份仍會完成。

## Build 0266 閒置自動備份登出
- 閒置 30 分鐘後，會先完整備份，再自動登出。
- 備份失敗時不會登出，會提醒使用者手動處理。
- 自動備份與登出會播放語音提示。

## Build 0265 登出強制備份
- 登出時只提供「完整備份後登出」。
- 移除「不備份直接登出」選項。
- 備份失敗時會留在系統內，不會登出。

## Build 0264 單筆付款刪除
- 付款明細新增「刪除本筆」按鈕。
- 需確認並輸入「刪除」才會執行，避免誤觸。
- 只刪除該筆付款、照片、支票照片與簽名，不影響其他資料。
- 若該筆使用系統支票，刪除後會恢復為未使用。

## Build 0263 廠商簽名頁面縮排
- 將金額、簽名區、清除重簽與確認收款按鈕集中在同一個手機畫面。
- 縮小簽名區高度與上下間距，仍保留足夠的手寫簽名空間。

## Build 0262 備份完成語音修正
- 按「立即完整備份」成功產生備份檔後，會確實播放「資料已備份完成」。
- 移除重複的備份語音事件，避免 iPhone 語音被取消或沒有播放。

## Build 0261 IndexedDB 儲存空間修正
- 當手機原有 localStorage 已滿時，付款資料、照片與廠商簽名會改用 IndexedDB 保存。
- 重新開啟系統會自動讀回 IndexedDB 內的完整資料，不需刪除既有付款照片。
- 保留原本完整備份與照片壓縮機制。

## Build 0260 手機儲存空間檢修
- 新拍照片進入系統時先縮小到適合手機儲存的尺寸與畫質。
- 廠商簽名先縮小再寫入，避免高畫質畫布造成儲存空間不足。
- 儲存失敗時會重新整理既有照片與簽名後再試，不會自動刪除已保存資料。
- 儲存仍不足時會明確提示先備份與清理手機空間，不會產生半筆付款紀錄。

## Build 025.9 簽名與照片保存檢修
- 拍照檔案會先經過讀取、格式與容量檢查，失敗時會顯示原因，不會留下半筆資料。
- 拍照後顯示目前加入的照片張數與影像容量，方便在簽名前確認。
- 廠商簽名會檢查畫布是否真的有筆跡，空白畫布不能送出。
- 手機旋轉或視窗縮放時，簽名畫布會保留原有筆跡。
- 存檔後會重新讀回資料庫，確認照片數量、照片內容存在、支票照片與簽名已保存。
- 明細頁會標示請款單照片、支票照片與廠商簽名，並可點擊放大查看。
- 移除登入頁公開的「忘記密碼／恢復初始密碼」，避免任何人重設管理員密碼；密碼只能在登入後由系統設定修改。

## 本版更新
- 收款月份可輸入起訖區間，例如 2026/05～2026/07，並自動展開為 5、6、7 月。
- 既有多月份資料仍保留，報表與付款明細會以區間方式顯示。
- 新增「多種付款」：同一筆可拆成客票、雙發支票與現金，合計必須等於實付金額。
- 客票保留銀行、票號與到期日；雙發支票沿用票號清單並自動鎖定已使用票號。
- 簽名進行中完全不播放語音；停止操作 15 秒後才提醒一次「請按確認收款」。
- 保留離開簽名頁立即停止所有簽名語音。
- 保留方案10簽名版面與高畫質照片預覽。

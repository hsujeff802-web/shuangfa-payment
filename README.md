# 雙發付款管理系統 V8.3 Build 0313 授權驗證診斷版

## V8.3 Build 0313 單機授權測試版
- 授權狀態分為「已驗證並保存」與「已保存但驗證未通過」，不再把兩種狀態顯示成同一個「已保存」。
- 若 Safari 與主畫面 App 讀到不同環境的設備綁定授權，會直接顯示綁定不符、到期或尚未啟用的原因。
- 登入頁與系統設定會顯示目前瀏覽模式及各授權保存層的讀取結果，方便檢查 iPhone／iPad 重開後是否真的可恢復。
- 智慧語音提醒新增「系統自動／女聲／男聲」選項，會依手機或平板已安裝的中文系統語音選擇。
- 若裝置沒有可辨識的指定音色，系統會安全改用目前可用的中文聲音，不會造成付款流程中斷。
- 新手機／平板第一次開啟網址時，必須輸入公司專用授權碼才能進入登入頁。
- 授權可設定公司名稱、1 年、2 年或永久期限，也可綁定設備識別碼。
- Build 0308 以前已在本機使用的裝置會自動保留永久本機授權，不影響既有付款資料。
- 系統設定可查看授權公司、期限及本機設備識別碼；授權資料與付款資料都保存在本機，授權另有 IndexedDB 備援。
- 授權碼保存於 localStorage、獨立 IndexedDB 與 Cookie 三層位置，並在啟用後立即讀回驗證。
- 系統設定可按「檢查授權保存」，查看目前 iPad 使用的是 Safari 或主畫面 App，以及各儲存層是否正常。
- 使用一般瀏覽模式；私密瀏覽、清除網站資料、切換 Safari／主畫面 App 或更換網址入口，可能無法保留本機授權。
- 本版本是離線授權測試版；若要做到線上即時停用，後續仍需雲端授權伺服器。

## 本版更新
- 收款月份可輸入起訖區間，例如 2026/05～2026/07，並自動展開為 5、6、7 月。

# 雙發付款管理系統 V8.3 Build 0324 雲端版

這是目前唯一主版本：雲端授權版。

## 授權方式

- 裝置識別碼留白：測試版，最多操作 10 筆付款資料。
- 填入裝置識別碼：正式授權，可使用一年、兩年、永久或自訂到期時間。
- 測試版達到 10 筆後不能新增或存檔，但仍可查詢、列印與備份既有資料。
- 授權碼產生器放在總包的 `admin-license-generator` 資料夾，請只保存在管理者電腦，不要上傳到 GitHub。

## 資料與雲端

- 付款資料、照片、簽名與備份仍保存在使用者自己的手機、平板或電腦。
- 雲端只處理授權驗證、公司授權方案與裝置綁定，不會同步付款資料。
- 第一次開啟需要網路；授權驗證成功後，依設定的離線寬限期使用。

## 上線

## 重要

本版本不要與單機版或其他舊版檔案混合上傳。總包根目錄的說明檔才是本次安裝指示。

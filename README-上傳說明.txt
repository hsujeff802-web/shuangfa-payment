雙發付款管理系統 V8.3 Build 0322 個人單機版

本版設定：
1. 關閉雲端授權門禁，不會要求輸入公司授權碼。
2. 保留登入帳號、密碼、付款、照片、簽名、列印與本機備份功能。
3. 更新 GitHub Pages 的版本號、Service Worker 快取版本與載入查詢參數。
4. 這是個人單機版，不要與雲端授權測試版檔案混放。

上傳方式：
1. 解壓縮本資料夾內的所有檔案。
2. 開啟 GitHub：hsujeff802-web/shuangfa-payment。
3. 點 Add file → Upload files。
4. 將解壓縮後的檔案全部選取並拖入（要放在 repository 根目錄，不要再包一層資料夾）。
5. Commit changes 直接提交到 main。
6. 等 GitHub Pages 部署完成後，用一般 Safari 開啟：
   https://hsujeff802-web.github.io/shuangfa-payment/?v=83422
7. 第一次開啟要保持網路；若使用主畫面 App，先用 Safari 開一次新版網址，再回到主畫面 App。

注意：本版 cloud-config.js 已關閉雲端授權，付款資料、照片、簽名與備份只保存在本機。
